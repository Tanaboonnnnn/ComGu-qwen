# ComGu Qwen v0.1.1

This release fixes folder authorization for Qwen Studio.

## Changed

- Replaced the single chat-style Workspace selector with a checkbox on every folder.
- Multiple folders can be enabled for Qwen at the same time.
- Enabled folders are the direct file/edit/terminal authority for Qwen; no per-chat WorkspaceScope is required.
- Unticking a folder revokes access immediately.
- Windows command execution remains confined to the enabled folders by MXC and still fails closed if the sandbox is unavailable.
- Existing v0.1.0 `selectedRoot` state migrates to one enabled folder automatically.
- MCP/server version now matches the standalone app version (`0.1.1`).

## Qwen Studio

You do not need to recreate the MCP server. Install v0.1.1, open ComGu Qwen, tick the folders Qwen may use, and retry the tool call. If the app was restarted, copy the new MCP endpoint URL because its secret path changes on each launch.
